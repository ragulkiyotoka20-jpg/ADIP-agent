# Coral Incident Time-Machine Video

Remotion composition for the 66-second Incident Time-Machine product reel.

## Render

```powershell
npm.cmd install
npm.cmd run render
```

The final MP4 is written to `out/incident-time-machine.mp4`.

## Preview

```powershell
npm.cmd run studio
```

The composition is `IncidentTimeMachine`: 1920x1080, 30 fps, 1980 frames.
